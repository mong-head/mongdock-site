곧 출시

무엇을 도와드릴까요?

자주 묻는 질문을 먼저 확인해 보세요. 해결이 안 되면 앱 안에서 바로 신고할 수 있어요.

자주 묻는 질문문제 신고하기몽독 제거하기

자주 묻는 질문

시작하기

독이 안 보여요.

새로 설치하면 독은 평소에 숨어 있다가, 화면 끝에 마우스를 대면 나타나요. 늘 보이게 하려면 설정 → 독에서 “항상 보이기”를 고르세요.

작업 표시줄이 안 보여요.

몽독은 켜져 있는 동안 윈도우 작업 표시줄을 숨겨요. 설정 → 일반 → “윈도우 작업 표시줄 숨기기”를 끄거나, 알림 영역의 몽독 아이콘을 한 번 눌러 일시 정지하면 돌아와요. 몽독이 갑자기 꺼졌는데 작업 표시줄이 안 보이면, 몽독을 다시 켜거나 로그아웃했다가 다시 로그인하세요.

원격 접속으로 쓰는데 느려요.

설정 → 일반 → “가벼운 모드”를 켜면 애니메이션과 흐림 효과를 끄고 가볍게 동작해요.

회사 PC 에서도 쓸 수 있나요?

관리자 권한 없이 설치·실행돼요. 다만 회사 정책에 따라 작업 표시줄 숨기기·자동 실행·캘린더 받기 등이 막힐 수 있어요. 설치해도 되는지는 먼저 회사 규정을 확인해 주세요.

루틴과 앱 모음 판

루틴은 어떻게 만들어요?

넣고 싶은 앱을 원하는 자리에 띄워 둔 뒤, 독 빈 곳을 오른쪽 클릭 → “지금 화면을 루틴으로 저장…”을 누르면 돼요. 설정 → 독 → 루틴에서 새 루틴을 만들고 앱·링크·게임을 하나씩 넣을 수도 있어요. 끝낼 때는 루틴 아이콘을 오른쪽 클릭 → “루틴 끝내기”를 누르세요. 루틴이 연 창만 닫아요.

루틴이 저절로 열리나요?

기본은 직접 누를 때만 열려요. 시작 조건(헤드셋·모니터 연결, 컴퓨터 켜기, 시간 등)을 켜면 오른쪽 위에 “열까요?” 배너가 떠요. 같은 조건으로는 하루에 한 번만 물어요.

루틴 추천은 끌 수 있나요?

설정 → 독 → 루틴에서 끌 수 있어요. 추천을 세 번 연달아 거절해도 저절로 꺼져요. 설치하고 3일 동안은 묻지 않고, 그 뒤에도 일주일에 많아야 한 번 물어요.

잠자는 앱을 지우면 어떻게 돼요?

앱 모음 판의 “잠자는 앱”에서 앱을 고르고 “Windows에서 제거…”를 누르면 확인 카드가 먼저 떠요. 지우기를 누르면 앱마다 윈도우의 제거 창이 차례로 열리고, 그 창에서 마치면 지워져요. 지우기 싫으면 “선택한 앱 숨기기”로 판에서만 감출 수 있어요. 숨긴 앱은 “숨긴 앱”에서 되살려요.

알림과 달력

카카오톡 알림이 배너로 안 떠요.

카카오톡은 윈도우 알림 대신 자체 팝업을 띄워서 몽독 배너로 보여 줄 수 없어요. 대신 독의 카카오톡 아이콘에 빨간 점이 보여요.

네이버 캘린더를 연결할 수 있나요?

개인 네이버 캘린더는 iCal 구독 주소를 제공하지 않아 연결할 수 없어요. 구글·Outlook.com 캘린더는 iCal 주소를 복사한 뒤 설정 → 캘린더 → “클립보드에서 추가”를 누르면 돼요.

개인정보·구매·제거

앱 실행 기록이나 창 제목은 어디에 남나요?

이 PC 안에만 남아요. 루틴 추천에 쓰는 실행 기록은 앱과 시각만 14일 동안 둬요. 창 제목은 메모리에서만 세고 저장하지 않아요. 브라우저 주소창이나 방문 기록은 읽지 않아요. 앱 모음 판 빈자리를 오른쪽 클릭 → “자주 쓰는 앱 기록 (추천·정리에 써요)”을 끄면 기록을 멈추고 지워요. 사용 통계는 처음에 물어보고, 동의한 경우에만 개수만 보내요.

체험 기간이 끝나면 어떻게 되나요?

15일이 지나면 독과 상단바가 멈추고 윈도우 작업 표시줄이 원래대로 돌아와요. 한 번 구매(₩9,900)하면 설정 그대로 다시 쓸 수 있어요. 구독이나 광고는 없어요.

몽독을 지우기 전에 할 일이 있나요?

설정 → 정보 → “몽독 제거하기…”를 눌러 주세요. 작업 표시줄·자동 숨김·알림 소리를 원래대로 돌리고 윈도우의 앱 제거 화면을 열어 줘요.

루틴 실행 옵션

루틴 편집 → 앱 항목 ▸ → 「고급: 실행 옵션」에 적은 글은 앱을 열 때 그대로 넘어가요. 대부분은 비워 두면 돼요.

  • --new-window — 브라우저를 새 창으로 (0.6.1부터는 루틴의 브라우저가 늘 새 창이라 안 적어도 돼요)
  • --profile-directory="Profile 1" — 크롬·엣지·웨일의 특정 계정으로 (0.6.1부터는 「계정」에서 고르면 돼요)
  • -n — VS Code 새 창

어떤 옵션을 받는지는 앱마다 달라요. 그 앱의 도움말을 참고하세요.

알아 두세요

  • 카카오톡처럼 윈도우 알림 대신 자체 팝업을 띄우는 앱은 알림 배너에 나오지 않아요(독 아이콘의 빨간 점은 보여요).
  • 알림 소리를 바꾸면 처음 한 번은 다시 로그인해야 적용돼요.
  • 네이버 캘린더는 iCal 구독 주소를 제공하지 않아 연결할 수 없어요.
  • 루틴을 끝낼 때 저장할지 묻는 창은 닫지 않고 그대로 둬요.
  • 루틴을 연 뒤 몽독을 다시 시작하면, 그 루틴이 연 창을 알 수 없어 창은 직접 닫아야 해요.
  • 창을 하나만 띄우는 앱(카카오톡, 디스코드 등)이 이미 켜져 있으면 새로 열지 않고, 그 앱이 있는 데스크톱을 알려 줘요.
  • 잠자는 앱을 지우면 앱마다 윈도우의 제거 창이 차례로 열려요. 지울 수 없는 앱은 목록에 따로 표시돼요.
  • 윈도우 10 에서는 둥근 모서리·일부 아이콘 모양이 윈도우 11 과 다를 수 있어요.
  • x64 PC 전용이에요.

문제 신고하기

설정 → 정보 → “문제 신고하기…”가 가장 빨라요. 화면 캡처나 파일을 붙일 수 있고, 보내기 전에 함께 갈 내용을 확인할 수 있어요. 이메일·주소·사용자 이름·창 제목은 가린 뒤 보내요.

몽독 제거하기

설정 → 정보 → “몽독 제거하기…”를 누르세요. 작업 표시줄·자동 숨김·알림 소리를 원래대로 돌린 뒤 윈도우의 앱 제거 화면을 열어 줘요.
