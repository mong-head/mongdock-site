몽독 (mongdock)

화면 위에는 앱 메뉴·제어 센터·달력이 모인 상단바, 아래에는 앱을 켜고 고르는 독. 알림 배너와 화면 가운데 몽독 검색까지, 설정은 모두 클릭만으로 바꿔요.

Microsoft Store 출시 준비 중

윈도우 11, 윈도우 10 버전 2004 이상 · x64 PC · 15일 동안 모든 기능 무료 체험 후 한 번 구매 · 구독·광고 없음

둘러보기

이런 걸 해요

상단바

지금 쓰는 앱의 메뉴와 자주 쓰는 단축키, 소리·Wi-Fi·블루투스·배터리, 가상 데스크톱 이동, 다른 앱의 트레이 아이콘까지 화면 위 한 줄에.

제어 센터

화면 밝기(노트북 화면, 밝기 조절을 지원하는 외장 모니터), 야간 모드, 전원 모드를 클릭 한 번으로.

알림 배너

윈도우 알림을 화면 오른쪽 위 배너로. 시계를 누르면 앱별로 묶인 알림 목록이 나오고, 몽독에서 지우면 윈도우 알림 센터에서도 지워져요.

몽독 검색

Win+Space 로 화면 가운데 검색창. 앱, 윈도우 설정, 파일·폴더를 찾고 계산도 해요. 한글 초성 검색(ㅋㅋㅇㅌ → 카카오톡)도 돼요.

독

아래·왼쪽·오른쪽·위 어디든. 끌어서 순서 바꾸기, 창 미리 보기, 마우스를 올리면 커지는 확대, 라이트·다크 테마.

달력

한국 공휴일·대체공휴일·음력 표시. 구글·Outlook.com 캘린더의 iCal 구독 주소를 붙여 넣으면 일정이 보여요.

노트북과 여러 환경

배터리 부족 알림, 카메라·마이크 사용 표시, 모니터 여러 대, 고배율·세로 모니터, 원격 접속용 가벼운 모드. 한국어·영어.

클릭만으로

모든 설정을 클릭으로 바꾸고 바로 확인해요. 독과 상단바를 눌러도 쓰던 앱의 키보드 입력을 빼앗지 않아요.

믿고 쓸 수 있게

작업 표시줄은 그대로

몽독이 켜져 있는 동안만 윈도우 작업 표시줄을 숨기고, 일시 정지·종료하면 원래대로 돌려놔요.

PC 안에서만

알림 내용, 창 제목, 캘린더 주소는 이 PC 안에서만 쓰고 밖으로 보내지 않아요. 사용 통계는 처음에 물어보고 동의한 경우에만 보내요. 개인정보처리방침

깔끔하게 지우기

설정 → 정보 → "몽독 제거하기…"가 작업 표시줄·알림 소리를 원래대로 돌린 뒤 윈도우 앱 제거 화면을 열어 줘요.

알아 두세요

  • 카카오톡처럼 윈도우 알림 대신 자체 팝업을 띄우는 앱은 알림 배너에 나오지 않아요(독 아이콘의 빨간 점은 보여요).
  • 알림 소리를 바꾸면 처음 한 번은 다시 로그인해야 적용돼요.
  • 네이버 캘린더는 iCal 구독 주소를 제공하지 않아 연결할 수 없어요.
  • 윈도우 10 에서는 둥근 모서리·일부 아이콘 모양이 윈도우 11 과 다를 수 있어요.
  • x64 PC 전용이에요.

자주 묻는 질문

작업 표시줄이 안 보여요.

몽독은 켜져 있는 동안 윈도우 작업 표시줄을 숨겨요. 설정 → 일반 → "윈도우 작업 표시줄 숨기기"를 끄거나, 알림 영역의 몽독 아이콘을 한 번 눌러 일시 정지하면 돌아와요. 몽독이 갑자기 꺼졌는데 작업 표시줄이 안 보이면, 몽독을 다시 켜거나 로그아웃했다가 다시 로그인하세요.

몽독을 지우기 전에 할 일이 있나요?

설정 → 정보 → "몽독 제거하기…"를 눌러 주세요. 작업 표시줄·자동 숨김·알림 소리를 원래대로 돌리고 윈도우의 앱 제거 화면을 열어 줘요.

카카오톡 알림이 배너로 안 떠요.

카카오톡은 윈도우 알림 대신 자체 팝업을 띄워서 몽독 배너로 보여 줄 수 없어요. 대신 독의 카카오톡 아이콘에 빨간 점이 보여요.

네이버 캘린더를 연결할 수 있나요?

개인 네이버 캘린더는 iCal 구독 주소를 제공하지 않아 연결할 수 없어요. 구글·Outlook.com 캘린더는 iCal 주소를 복사한 뒤 설정 → 캘린더 → "클립보드에서 추가"를 누르면 돼요.

회사 PC 에서도 쓸 수 있나요?

관리자 권한 없이 설치·실행돼요. 다만 회사 정책에 따라 작업 표시줄 숨기기·자동 실행·캘린더 받기 등이 막힐 수 있어요. 설치해도 되는지는 먼저 회사 규정을 확인해 주세요.

원격 접속으로 쓰는데 느려요.

설정 → 일반 → "가벼운 모드"를 켜면 애니메이션과 흐림 효과를 끄고 가볍게 동작해요.

체험 기간이 끝나면 어떻게 되나요?

15일이 지나면 독과 상단바가 멈추고 윈도우 작업 표시줄이 원래대로 돌아와요. 구매하면 설정 그대로 다시 쓸 수 있어요.

문의

앱 안 설정 → 정보 → "문제 신고하기…"가 가장 빨라요. 이메일은 mongdock+help@gmail.com 으로 보내 주세요.
