常见问题

入门

看不到程序坞。

新安装后，程序坞会一直隐藏，直到你把鼠标移到屏幕边缘。想让它一直显示，请在设置 → 程序坞中选择“始终显示”。

看不到任务栏。

mongdock 运行时会隐藏 Windows 任务栏。关闭设置 → 通用 →“隐藏 Windows 任务栏”，或在通知区域点按一下 mongdock 图标暂停，任务栏就会回来。如果 mongdock 意外退出而任务栏仍然隐藏，请重新启动 mongdock，或注销后重新登录。

通过远程桌面使用时感觉很慢。

打开设置 → 通用 →“轻量模式”，即可关闭动画和模糊效果。

能在公司电脑上用吗？

无需管理员权限即可安装和运行，但公司策略可能会阻止隐藏任务栏、登录时启动或下载日历。请先确认公司的规定。

例程与所有应用

怎样创建例程？

先打开想要的应用，摆到喜欢的位置，然后右键点按程序坞空白处 →“将当前屏幕存为例程…”。也可以在设置 → 程序坞 → 例程中新建例程，逐个添加应用、链接和游戏。结束时，右键点按例程图标 →“结束例程”，只会关闭例程打开的窗口。

例程会自己打开吗？

默认只在你点按时打开。打开开始条件（连接耳机或显示器、打开电脑、设定的时间等）后，右上角会出现横幅，问你要不要打开。同一条件每天最多问一次。

可以关闭例程推荐吗？

可以，在设置 → 程序坞 → 例程中关闭。连续拒绝三次也会自动关闭。安装后的前 3 天不会推荐，之后最多每周问一次。

卸载沉睡的应用会怎样？

在“所有应用”面板中打开“沉睡的应用”，选好应用后点按“在 Windows 中卸载…”，会先出现确认卡片。之后会依次打开每个应用的 Windows 卸载程序，在那里完成即可删除。如果想保留某个应用，用“隐藏所选应用”只在面板中隐藏它。隐藏的应用可以在“隐藏的应用”中找回。

隐私、购买与卸载

应用使用记录和窗口标题保存在哪里？

只在你的电脑上。用于例程推荐的启动记录只保留应用和时间，保存 14 天。窗口标题只在内存中计数，从不保存。mongdock 不读取浏览器的地址栏和浏览记录。要停止并清除这些记录，请右键点按“所有应用”面板空白处，关闭“记录常用应用（用于推荐和整理）”。使用统计仅在首次询问时你同意后发送，而且只有次数。

试用期结束后会怎样？

15 天后，程序坞和菜单栏会停止，Windows 任务栏会恢复。一次性购买 mongdock 后，设置原封不动，接着用。无订阅，无广告。

卸载前要做什么吗？

前往设置 → 关于 →“卸载 mongdock…”。它会恢复任务栏、自动隐藏和通知声音，并打开 Windows 的卸载页面。

须知

  • 第一次更改通知声音后，需要注销并重新登录才会生效。
  • 结束例程时，正在询问是否保存的窗口会保留不关。
  • 打开例程后如果重启 mongdock，就无法知道哪些窗口是例程打开的，需要你自己关闭。
  • 只运行一个窗口的应用（如 Discord）如果已经在运行，就不会再打开，mongdock 会告诉你它在哪个桌面上。
  • 卸载沉睡的应用时，会依次打开每个应用的 Windows 卸载程序。无法用这种方式卸载的应用会在列表中标出。
  • 在 Windows 10 上，圆角和部分图标可能与 Windows 11 看起来不同。
  • 仅支持 x64 电脑。

报告问题

最快的方法是设置 → 关于 →“报告问题…”。可以附上截图或文件，发送前能确认具体包含哪些内容。邮箱、网址、用户名和窗口标题会先打码再发送。

卸载 mongdock

前往设置 → 关于 →“卸载 mongdock…”。它会恢复任务栏、自动隐藏和通知声音，然后打开 Windows 的卸载页面。
