安心使用

只留在你的電腦上

App 使用紀錄、視窗標題、例行程序和通知內容，只在這台電腦上使用。mongdock 不會讀取瀏覽器的網址列和瀏覽紀錄。使用統計只在你同意時傳送，而且只有次數。

工作列會回來

mongdock 只在執行時隱藏 Windows 工作列。暫停或結束後，它就會回到原處。

移除也乾淨

「解除安裝 mongdock…」會先恢復工作列、自動隱藏和通知音效，再開啟 Windows 的解除安裝頁面。
