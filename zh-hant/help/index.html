常見問題

開始使用

看不到 Dock。

剛安裝時，Dock 會保持隱藏，直到你把滑鼠移到畫面邊緣。想讓它一直顯示，請在設定 → Dock 中選擇「一律顯示」。

看不到工作列。

mongdock 執行時會隱藏 Windows 工作列。關閉設定 → 一般 →「隱藏 Windows 工作列」，或在通知區域按一下 mongdock 圖示暫停，工作列就會回來。如果 mongdock 意外結束而工作列仍然隱藏，請重新啟動 mongdock，或登出後再重新登入。

用遠端桌面時感覺很慢。

開啟設定 → 一般 →「輕量模式」，即可關閉動畫和模糊效果。

可以在公司電腦上使用嗎？

不需要系統管理員權限就能安裝和執行，但公司政策可能會封鎖隱藏工作列、登入時啟動或下載行事曆。請先確認公司的規定。

例行程序與所有應用程式

要怎麼建立例行程序？

先開啟想要的 App，擺到喜歡的位置，然後在 Dock 空白處按右鍵 →「將目前畫面儲存為例行程序…」。也可以在設定 → Dock → 例行程序中新增例行程序，逐一加入 App、連結和遊戲。結束時，在例行程序圖示上按右鍵 →「結束例行程序」，只會關閉例行程序開啟的視窗。

例行程序會自己開啟嗎？

預設只在你按下時開啟。開啟開始條件（接上耳機或顯示器、打開電腦、設定的時間等）後，右上角會出現橫幅，詢問要不要開啟。同一條件每天最多問一次。

可以關閉例行程序推薦嗎？

可以，在設定 → Dock → 例行程序中關閉。連續拒絕三次也會自動關閉。安裝後的前 3 天不會推薦，之後最多每週問一次。

解除安裝沉睡的 App 會怎樣？

在「所有應用程式」面板開啟「沉睡的 App」，選好 App 後按「在 Windows 中解除安裝…」，會先出現確認卡片。接著會依序開啟每個 App 的 Windows 解除安裝程式，在那裡完成即可移除。如果想保留某個 App，用「隱藏所選 App」只在面板中隱藏它。隱藏的 App 可以在「隱藏的 App」中找回。

隱私權、購買與解除安裝

App 使用紀錄和視窗標題存在哪裡？

只在你的電腦上。用於例行程序推薦的啟動紀錄只保留 App 和時間，存放 14 天。視窗標題只在記憶體中計數，從不儲存。mongdock 不會讀取瀏覽器的網址列和瀏覽紀錄。要停止並清除這些紀錄，請在「所有應用程式」面板空白處按右鍵，關閉「記錄常用 App（用於推薦和整理）」。使用統計只在第一次詢問時你同意後才傳送，而且只有次數。

試用期結束後會怎樣？

15 天後，Dock 和選單列會停止，Windows 工作列會恢復。一次買斷 mongdock 後，設定原封不動，接著使用。不用訂閱，沒有廣告。

解除安裝前要做什麼嗎？

前往設定 → 關於 →「解除安裝 mongdock…」。它會恢復工作列、自動隱藏和通知音效，並開啟 Windows 的解除安裝頁面。

須知

  • 第一次變更通知音效後，需要登出再重新登入才會生效。
  • 結束例行程序時，正在詢問是否儲存的視窗會保留不關。
  • 開啟例行程序後如果重新啟動 mongdock，就無法得知哪些視窗是例行程序開的，需要你自己關閉。
  • 只執行一個視窗的 App（例如 Discord）如果已經在執行，就不會再開啟，mongdock 會告訴你它在哪個桌面。
  • 解除安裝沉睡的 App 時，會依序開啟每個 App 的 Windows 解除安裝程式。無法用這種方式解除安裝的 App 會在清單中標示出來。
  • 在 Windows 10 上，圓角和部分圖示可能和 Windows 11 看起來不同。
  • 僅支援 x64 電腦。

回報問題

最快的方法是設定 → 關於 →「回報問題…」。可以附上螢幕擷取畫面或檔案，傳送前能確認會一起送出的內容。電子郵件、網址、使用者名稱和視窗標題會先遮住再傳送。

解除安裝 mongdock

前往設定 → 關於 →「解除安裝 mongdock…」。它會恢復工作列、自動隱藏和通知音效，然後開啟 Windows 的解除安裝頁面。
